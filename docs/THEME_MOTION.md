# Theme visual references and motion

The references establish identity and physical or cultural visual anchors. Geometry, timing and motion are original artistic interpretations, not canonical game animations or scientific simulations. Existing artwork credits remain in place. No reference images are imported.

Motion uses CSS transforms and opacity. System reduced motion and the Animations control show composed stills; hidden tabs and optimizer searches freeze movement. The seven Elemental backgrounds retain their artwork, palette and composition.

**Still:** Existing fissures, flame artwork, and palette remain unchanged; a few stationary embers provide depth.

**Reference qualification:** Replace the inaccessible archived USGS page. Volcanic cinders and burning vegetation embers are distinct physical phenomena.

**Motion-only refinement:** Retain all current artwork, composition, stream geometry, and colors. Adjust existing ember trajectories into staggered upward acceleration with a coherent wind bend. Replace synchronized pulsing with individual lifetimes. Mobile halves particle density and disables pointer parallax. Reduced motion stops all decorative animation.
